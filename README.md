## 🗺️ Ringkasan alur operasional

```
Persiapan (Ags–Sep 2026)
   │  visa J-1/DS-2019 → tiket → asuransi → vaksin → packing
   ▼
Keberangkatan (~26–27 Sep 2026)
   │  CGK → transit → ONT/LAX → shuttle/rental car → Riverside
   ▼
Masa Studi di UCR (28 Sep – ~19 Des 2026, ~12 minggu)
   │  kelas + riset + akhir pekan eksplorasi California
   ▼
Kepulangan (~20–25 Des 2026)
   │  checkout housing → packing oleh-oleh → LAX/ONT → transit → CGK
   ▼
Pasca-kepulangan
   │  laporan akhir LPDP, reintegrasi, follow-up
```
